# TDT CAN Setup - updates

Update channel for **TDT CAN Setup** (tool for the J1939 CANBUS module).

- The program checks `releases/latest` for a newer version and installs it itself ("Update now").
- **New PC:** download `TDT-CAN-Setup-<version>.zip` from the latest release, extract it (e.g. to `D:\TDT CAN Setup`), run `TDT CAN Setup.exe`.

新电脑:在最新 Release 下载 `TDT-CAN-Setup-<版本>.zip`,解压后运行 `TDT CAN Setup.exe`。之后程序会自动提示更新。
